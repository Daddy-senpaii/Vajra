# Product

Vayra is an Android-first self-improvement platform for challenge discovery, daily progress, personal analytics, and accountability with friends. The product principle is to support both private improvement and growth with friends.

The MVP follows the feature tree and phase order in [AGENT.md](../AGENT.md). Current implementation scope is Phase 1: a launchable Android shell and a Go API foundation backed by MongoDB. Application features must be delivered in separate feature branches after foundation approval.

Core navigation and feature requirements are defined in `AGENT.md`; this document records the product summary and should stay aligned with that source.
